# API AutoPop - Aplicativo Mobile

# Stack
- PHP
  - PDO
  - Composer
- MySQL

# Desenvolvimento

## Como executar

-Na raíz do projeto, execute o comando `composer install` para instalar as dependencias localmente, criando a pasta *vendor/*
-Crie um arquivo *.env* que será uma cópdia do *.env.example* e preencha os campos com os dados corretos para execução das variáveis por todo projeto
-Navegue até a pasta *src/public* e execute o comando `php -S localhost:8080` para executar o projeto. Use o Imsomnia ou Postman para testar as chamadas
